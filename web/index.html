Installation & Fast Credential Audit

Crackerjack is a lightweight, zero-dependency identity security and active cyber deception engine for enterprise infrastructure, CI/CD pipelines, and active directories.

# 1. Install via pip or standalone package pip install crackerjack-audit # 2. Audit credentials with NIST SP 800-63B policy enforcement crackerjack audit hashes.txt --report audit.html --smart-mutations # 3. Assess cryptographic KDF migration risks (MD5, NTLM -> Argon2id) crackerjack hygiene /etc/shadow --output-json

Outputs include executive HTML reports with pure SVG vector donuts, broken password breakdown charts, and longitudinal drift tracking.

Active Cyber Deception & Honeywords

Juels-Ristenpart active honeywords generation with exact character-entropy pool matching, making decoy canaries mathematically indistinguishable to offline attackers.

# Generate 5 decoy honeywords matching legitimate password entropy crackerjack honey generate --password "K9#mQ2$pL8v" --count 5 # Inject canaries into /etc/shadow or Windows Active Directory NTDS crackerjack honey inject --format shadow --user svc_backup # Tripwire verification: trigger instant SIEM alert on credential stuffing crackerjack honey verify --attempted "K9#mQ2$pL8v" --canary-file canaries.json
